# Portfolio Website

IN PROGRESS!!!

My personal portfolio, showcasing design and web development projects.

Built with React 19, TypeScript, Vite 8, Tailwind CSS 4, Motion and React Router.

Intended deployment target: [makidonk.github.io](https://makidonk.github.io/).

## Local development

Requires Node.js 22.12+ (Node 24 LTS recommended) and npm.

```bash
npm ci
npm run dev
```

## Commands

- `npm run dev` - start the development server.
- `npm run build` - type-check and build into `dist/`.
- `npm run preview` - preview the production build locally.
